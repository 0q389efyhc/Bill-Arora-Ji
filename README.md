# Arora Road Carrier — Transport Bill

Streamlit app that matches the paper GR form. Every bill is saved in SQLite and can be downloaded again as PDF.

## Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

On Mac/Linux use `source .venv/bin/activate` instead of the Windows activate line.

The database file `bills.db` is created next to `app.py` the first time you save a bill.
